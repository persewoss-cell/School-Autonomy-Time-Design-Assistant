# 학교자율시간 설계 도우미 앱

초등학교 3~6학년 학교자율시간 **과목·활동**을 단계별로 설계하도록 돕는 웹 서비스입니다.
(기준: 「2027학년도 초등 학교자율시간 설계·운영 지침」, 전라남도교육청 · 2027 설계·운영 역량강화 연수 자료)

## 할 수 있는 것
- **설계 단계** (문서 작성 부분은 연수 PPT 순서)
  유형 → 기본 정보 → [전단계] 활동 내용 선정 → 내용 체계 → 핵심아이디어 → 성취기준 → 필요성(성격)·목표
  → 단원 지도계획 → 평가 계획 → (과목) 교수·학습 → 계획서/신청서 → 점검·내려받기
- **AI에게 초안 받기**: 단계마다 앱이 만든 프롬프트를 복사해 각자 쓰는 AI(ChatGPT, Claude, Gemini 등)에 붙여 넣고,
  AI의 답을 다시 붙여 넣으면 읽어 옵니다. **AI 키·비용 없음.** 확정한 목록에 없는 내용 요소·성취기준 코드는 자동으로 걸러 냅니다.
- **자동 점검**: 시수, 내용 요소 서술어미, 성취기준 코드·범주 결합, 목표 3개, 성취기준 단원 배치, 평가 계획 A·B·C,
  평가 내용의 단원 지도계획 반영, 체크리스트(서식6·7) 등 — 어느 항목이 / 왜 / 어떻게 고치면 되는지 보여 줌
- **문서 내려받기 (.docx, 한글에서 열림) / PDF로 받기(인쇄 창에서 PDF로 저장)**: 활동은 서식1·2·6, 과목은 서식3·4·7. 교육과정 문서는 예시안(광양중동초)과 같은 모양
- **시수 점검** (`/hours`): 시수 편성 점검표(엑셀)와 같은 계산식, 편성표 .docx 내려받기
- **계정은 학교 단위 (한 학교당 1개)**: 회원가입은 지역(시·군·구, 가나다 순) → 학교 정식 명칭 → 비밀번호·확인, 관리자 승인 후 사용.
  로그인은 학교명 + 비밀번호. 비밀번호를 잊으면 로그인 화면에서 관리자에게 재설정 신청 → 관리자가 임시 비밀번호 발급
- **로그인·저장·내 설계**, **관리자 모드** (가입 승인, 임시 비밀번호 발급, 전체 설계 열람, 이용 기록, 통계)
- **예시 불러오기**: 광양중동초 「지구마을 첫걸음」 과목 완성본

## 환경 변수 (Vercel → Settings → Environment Variables)
| 이름 | 설명 | 없으면 |
|---|---|---|
| `MONGODB_URI` | MongoDB Atlas 접속 주소 (`mongodb+srv://...`) | 로그인·저장·관리자 기능 꺼짐 (설계·내려받기는 됨) |
| `MONGODB_DB` | 데이터베이스 이름 (기본 `school_autonomy`) | 기본값 사용 |
| `AUTH_SECRET` | 로그인 비밀키, 32자 이상 무작위 문자열 | 로그인 기능 꺼짐 |
| `ADMIN_SCHOOLS` | 가입하면 바로 관리자가 되는 학교 정식 명칭 (쉼표로 구분, 예: `광양중동초등학교`) | 관리자 없음 |

설정한 뒤 사이트의 **설정 확인**(`/status`) 화면에서 모두 '정상'인지 확인하세요.

## 내 컴퓨터에서 실행하기
1. [Node.js](https://nodejs.org) LTS 버전 설치
2. 터미널에서 이 폴더로 이동한 뒤 `npm install`
3. `.env.example`을 복사해 `.env`를 만들고 값을 채웁니다. (시험만 할 때는 `MONGODB_URI=memory`)
4. `npm run dev` 실행 후 브라우저에서 http://localhost:3000 접속
