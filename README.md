# 학교자율시간 설계 도우미 앱

초등학교 3~6학년 학교자율시간 **과목·활동**을 단계별로 설계하도록 돕는 웹 서비스입니다.
(기준: 「2027학년도 초등 학교자율시간 설계·운영 지침」, 전라남도교육청)

## 지금 되는 것 (1~2단계)
- 과목/활동 선택 → 기본 정보(학년·학기 고르면 시수 자동) → 주제와 내용 입력
- AI 단원 지도계획 3안 추천 (API 키가 없으면 **체험 모드** 예시)
- 고른 안의 차시 고치기 + 시수 자동 점검 (29/32시간, 최소 10차시, 과정중심평가 포함 여부)
- **시수 점검** (`/hours`): 학교자율시간 시수 편성 점검표(엑셀)와 같은 계산식으로 교과별 증감 범위(±20%), 체육·음악·미술 감축 불가, 학년군 총시수, 학기별 29/32시간을 점검
- `/status` 화면에서 API 키·DB 연결 확인

## 내 컴퓨터에서 실행하기
1. [Node.js](https://nodejs.org) LTS 버전 설치
2. 터미널에서 이 폴더로 이동한 뒤 `npm install`
3. `.env.example`을 복사해 `.env`를 만들고 값을 채웁니다. (비워 두면 체험 모드로 동작)
4. `npm run dev` 실행 후 브라우저에서 http://localhost:3000 접속

## 인터넷에 올리기 (Vercel)
1. https://vercel.com 에 GitHub 계정으로 가입
2. **Add New → Project** → 이 저장소 **Import**
3. **Environment Variables**에 `.env.example`의 이름대로 값 입력 (없으면 체험 모드)
4. **Deploy** → 생성된 주소로 접속

## 테스트
`npm test` — 시수 점검 규칙 등이 지침대로 동작하는지 확인합니다.
