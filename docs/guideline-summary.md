# 지침 요약 (검증 규칙의 근거)

출처: 「2027학년도 초등 학교자율시간 설계·운영 지침」(전라남도교육청 유초등교육과, 2026. 6.),
2027 설계·운영 역량강화 연수 PPT, 설계 실습 양식, 예시 문서(「지구마을 첫걸음」 과목, 「지구촌, 함께 걷는 우리」 활동).

> 각 항목 끝의 `[E]`는 코드가 **오류**로 막을 규칙, `[W]`는 **경고**만 띄울 규칙, `[M]`은 교사가 직접 확인(체크리스트)할 항목이다.

## 3. 문서 항목별 작성 규칙

### 성격 (과목)
- 과목의 고유 성격 + 필요성 및 역할 + 기르고자 하는 역량.
- 총론의 '추구하는 인간상', '초등학교 교육목표'와 연계.

### 필요성 (활동)
- 사회현상 및 시대적 요구 + 학생들이 배워야 하는 까닭 + 기르고자 하는 학생상 혹은 역량.

### 목표
- **총괄 목표 1개 + 세부 목표 3개**(지식·이해 / 과정·기능 / 가치·태도). [E]

### 내용 체계
- 핵심아이디어: 학습을 통해 일반화할 수 있는 진술문. 영역 수 ≒ 핵심아이디어 수. [W]
  - 당위 표현("~해야 한다") 지양 [W], 낱말 풀이식 진술 지양 [M].
- 영역: 2~3개 권장 [W]. 명사형.
- 내용 요소 서술어미 [W]:
  - **지식·이해**: 명사형. (X) "평화의 중요성 알기" → (O) "평화의 중요성"
  - **과정·기능**: "~하기"로 끝남. 주된 종결어: 문제해결하기, 관찰하기, 탐구하기, 자료수집하기, 답사하기, 면담하기, 해결 방법 모색하기, 자료 정리하기, 설명하기, 해석하기, 표현하기, 예상하기, 분석하기, 결론 도출하기, 비교·분석하기, 공유하기, 주장하기, 설계하기, 소통하기, 성찰하기, 제작하기, 평가하기, 활용하기, 감상하기, 움직이기, 경기하기, 이야기하기, 발표하기, 창작하기 등
  - **가치·태도**: 명사형. 주된 종결어: 태도, 흥미, 인식, 자세, 가치관, 감수성, 실천, 배려, 존중, 민감성, 내면화, 즐거움, 호기심, 관용, 효능감, 창의성, 자기존중, 어울림, 문화 향유 등
- 특정 브랜드·지역명 기술 지양 [W/M].

### 성취기준
- 코드 형식 [E]: `[편성학년][편성교과 맨 앞 글자][과목명 앞 글자 또는 요약 2~3자][영역 순서 2자리]-[영역 내 순서 2자리]`
  - 예: `[4과디탐01-01]`, `[6사지구촌02-01]`, `[3사지구01-01]`
  - 2027 변경: 예전 형식 `[4디탐01-01]`(교과 글자 없음)은 사용 불가.
- 영역별 2개 이상 [W].
- 지식·이해 / 과정·기능 / 가치·태도 중 **두 가지 이상 범주를 결합**해 진술 [W]. 지식·이해만으로 진술 지양 [W].
  - 앱 규칙 [E: 사용자 결정, 2026-10-30]: 성취기준 하나에 내용 요소 **2개 또는 3개**, **서로 다른 범주**에서 하나씩 묶는다.
    2개면 서로 다른 두 범주, 3개면 지식·이해 + 과정·기능 + 가치·태도. 같은 범주끼리 묶지 않는다.
    그래서 한 영역에서 한 범주의 내용 요소 수가 나머지 두 범주를 합한 수보다 많으면 성취기준을 만들 수 없다(내용 체계 오류).
- 내용 체계의 내용 요소와 연계 [E: 각 성취기준은 1개 이상의 내용 요소와 연결].
- 문장은 "~한다."처럼 끝맺음 [W]. **"~할 수 있다."로 끝맺지 않음** [E: 사용자 결정, 2026-10-30] (성취수준 A·B·C 진술은 해당 없음).

### 지도의 실제 — 단원 지도계획
- 열: 단원명 / 성취기준 / 차시 / 학습주제 / 학습 내용 / 비고.
- 단원명 = 영역명 그대로 또는 영역을 포함하는 의미로 재구성.
- 차시 표기 `n/전체` 또는 `n~m/전체`. 차시가 1부터 전체까지 빠짐·겹침 없이 이어져야 함 [E]. 전체 = 운영 시수 [E].
- 학습 내용은 "· 학습 목표(~해 봅시다)" + "- 세부 활동" 형식.
- 앱 규칙 [E: 사용자 결정, 2026-10-30]
  - [전단계]에서 적은 '하고 싶은 활동'은 실제 수업이므로 모두 어느 차시엔가 들어가야 한다 (차시마다 연결한 활동을 저장해 코드로 확인).
  - 과정중심평가는 **성취기준마다 정확히 1개**, 그 성취기준을 배치한 단원에서 그 성취기준의 내용을 배우는 차시에 둔다.
    (성취기준이 4개면 과정중심평가 차시 4개)
  - 단원별 최소 차시 규칙은 없음 (사용자 확인, 2026-10-30). 최소 10차시는 과목/활동 전체 기준.
  - AI에게 묻기 전에 교사가 단원별 차시(빈칸은 추천: 운영 시수를 내용 요소 수 비율로, 합계 = 운영 시수),
    '단원 지도계획에 반드시 넣을 내용', '기타 참고사항'을 적고, 모두 프롬프트에 들어간다.
- **평가 계획의 평가 내용이 단원 지도계획에 반드시 포함**(`[과정중심평가] ...` 표기) [E].
- 비고: 마을학교 연계, 코티칭, 원어민 연계 등.

### 지도의 실제 — 평가 계획
- 열: 시기(월) / 성취기준 / 수업·평가 방법, 연계의 주안점 / 성취수준(A·B·C) / 방법.
- 과목은 **모든 성취기준에 성취수준 작성** [E]. 두 개의 성취기준을 묶어 평가 가능.
- 방법 예: 관찰평가, 자기평가, 동료평가, 상호평가, 서술형평가, 수행평가, 구술평가, 포트폴리오평가, 지필평가, 체크리스트평가, 일화기록평가, 프로젝트평가, 발표평가, 토의·토론평가, 산출물평가.

### 교수·학습 방법 및 평가 (과목)
