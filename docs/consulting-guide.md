# 학교자율시간 계획서 컨설팅 기준 (메모 작성 방법)

다른 학교의 학교자율시간 계획서(한글 hwpx)를 컨설팅할 때 쓰는 기준이다.
2026-11 광양 지역 학교(마동초 3~6학년, 가야초 3·5학년, 북초 3~6학년) 활동 문서 컨설팅에서 사용자가 직접 고친 메모(3회)를 바탕으로 정리했다.
다른 학교 문서가 오면 이 기준으로 메모를 달고, 사용자가 고쳐 보내면 달라진 점을 이 문서에 더한다.
근거: 「2027학년도 초등 학교자율시간 설계·운영 지침」, 2027 연수 PPT, 앱 규칙(`docs/guideline-summary.md`).
모범 양식: 「지구촌, 함께 걷는 우리」(활동 예시안) — 학교에 '제공한 양식'으로 안내한다.

## 1. 결과물

- 원본 hwpx에 **한글 메모**를 단 파일 (작성자 `컨설팅`). 만드는 방법은 아래 5절.
- 메모가 안 열릴 때를 대비한 쪽·줄 목록(docx)은 요청이 있을 때만.

## 2. 메모 말투·형식 (사용자가 고친 형태)

- **첫 줄 = `[구분] 짧은 진술`**. 한 줄로 끝나면 그것만 쓴다. 예: `[필수] 활동명과 다름.`, `[권장] 삭제`
- 필요할 때만 한두 문장 덧붙인다. 설명을 길게 쓰지 않는다.
- 종결은 **'~함 / ~임 / ~필요'** (개조식). '~요, ~니다'는 쓰지 않는다.
- 판단이 들어가면 단정하지 않는다: `~가까워 보임`, `~거리가 있어 보임`, `~가 아닌가 함`, `~어렵지 않을까 싶음`.
- 성취기준 코드 대신 **단원 이름**으로 가리킨다: `2단원 기후변화와 자원 고갈 내용에 가까워 보임`.
- 고칠 모양을 보여 줄 때는 `고친 예: …` (짧은 것) 또는 `(예시)` 다음 줄부터 모범 양식 문장을 그대로(여러 줄).
- **구분 표시는 `[필수]`와 `[권장]` 두 가지만 쓴다** (사용자 결정, 2026-11-23).
  - `[필수]` 반드시 고쳐야 하는 것: 지침·양식 근거, 연수 자료 근거, 사실·계산·오타 확인(예전의 지침·연수·확인 표시).
    양식·문장 모양(필요성 한 문단, '이에 따라 <활동명>는~', 학습 내용 기술 방법, 핵심아이디어 진술 방식),
    내용 요소가 모두 성취기준에, 과정·기능 '~하기', 평가 차시 표시, **영역별로 나누기**, 편성표 활동명·시수 메모도 모두 `[필수]`.
  - `[권장]` 더 좋게 하자는 것: '~한다.' 진술, 다른 학년 전제 문장 삭제, 가치·태도가 활동 성격, C 수준 긍정형,
    차시가 성취기준과 거리가 있음, 학년 수준에 어려움, 용어 바꾸기(로컬푸드 → 우리 지역에서 나는 식재료) 등.
  - 구분 표시가 없는 메모는 만들지 않는다 (있으면 `[권장]`을 붙인다).
  - 예전 표시가 남은 파일은 `relabel.py`로 바꾼다.

### 1. 필요성 및 목표
| 자리 | 메모 |
|---|---|
| `필요성 및 목표` 제목 (필요성이 여러 문단) | `[필수]사회현상 및 시대적 요구 + 학생들이 해당 활동을 배워야 하는 까닭 + 기르고자 하는 학생상 혹은 역량을 한 문단으로 기술` |
| 총괄 목표 문단이 `이를 위해`로 시작 | `[필수] 이에 따라 <활동명>는~ 시작하도록 변경` |
| 다른 학년 활동을 배웠다고 전제한 문장(그 학생들은 아직 안 배움) | 문장마다 `[권장] 삭제` |
| 세부 목표 3개가 순서대로 지식·이해 / 과정·기능 / 가치·태도에 맞는지 | 어긋나면 `[필수] 지식이해 목표가 아닌 과정기능 목표에 해당됨`, `[필수] 가치태도의 목표와 맞지 않음` (어긋난 구절에) |

### 2. 내용 체계
| 자리 | 메모 |
|---|---|
| 핵심아이디어가 '학생들이 …하도록 한다', '…교육은 …목표로 한다' | `[필수] 핵심아이디어 진술 방식` / `핵심아이디어는 '활동의 학습을 통해 일반화할 수 있는 내용을 핵심적으로 기술'함. 현재 문장은 교육 목표에 가까움.` (+ 개수가 영역 수와 다르면 `영역(2개)과 핵심아이디어(3개)의 수도 맞지 않음.`) |
| `내용 요소` 머리칸 (영역 구분 없음) | `[필수] 각 영역별로 나누기` / `단원이 3개이므로 영역이 3개로 나뉘어야 하며, 성취기준도 각 영역별로 2-3개씩 있어야 함.` |
| 과정·기능 요소가 '~하기'가 아님 | `[필수] 과정·기능 내용 요소는 '~하기'` + `고친 예:` |
| 가치·태도에 활동이 들어감('실천 계획 수립' 등) | `[권장] 활동(과정·기능) 성격임.` + `고친 예: …태도/의지` |
| 가치·태도가 한 차시 활동 서술 | `[권장] 한 차시 활동에 가까움.` + `고친 예:` |
| 영역명이 단원명과 같은 문장형('~해요', '~우리') | `[권장] 영역명은 단원명과 다르게, 영역 내용을 대표하는 간결한 명사형으로 진술` + `고친 예: 우리 고장 탐구` (첫 영역에만 길게, 둘째는 짧게) |
| 내용 요소가 성취기준 표현과 어긋남 | `[권장] 1단원 성취기준은 ‘경험과 느낌을 … 표현’이므로 내용 요소도 이에 맞추는 것이 좋아 보임.` + `고친 예:` |

### 3. 성취기준
| 자리 | 메모 |
|---|---|
| `3. 성취기준` 제목 (성취기준에 안 들어간 내용 요소가 있음) | `[필수] 내용 요소의 모든 내용들이 성취기준에 들어가야함. 누락 부분 밑줄 밑 기울임 표시` — 사용자는 빠진 요소를 메모에 나열하지 않고 **본문 내용 요소 글자에 밑줄·기울임**으로 표시함 (빠진 요소는 성취기준과 하나씩 대조해서 찾음) |
| 첫 성취기준 코드 (교과 글자 없음 / 약어 1글자) | `[필수] 성취기준 코드에 편성교과 글자가 없음` + `고친 예: [3과지구01-01]` |
| 성취기준에 맞는 내용 요소가 없음 (반대 방향) | `[필수] 이 성취기준에 맞는 내용 요소가 없음.` / `[필수] ‘다른 사람과 소통’은 내용 요소에 없음.` + 넣거나 빼기 |
| 영역에 성취기준이 1개뿐 | `[필수] 영역별 성취기준은 2~3개씩 있어야 함.` |
| 첫 '~할 수 있다' 문장 (한 번만) | `[권장] 성취기준은 '학생이 도달할 결과'이므로 2022 개정 교육과정처럼 '~한다.'로 진술하면 더 분명함.` |

### 붙임2 편성표
- 숫자(학기별 증감·편성, 소계, 창체, 연간 총시수, 교과(군) 20% 범위, 체육·예술 감축 금지, ※ 확보 내역 합계)를 계산해 확인. 맞으면 메모 없음.
- 학교자율시간이 아닌 교과 증감(예: 수학 증)을 위해 줄인 시수가 학교자율시간 학기와 다른 학기에 섞여 학교자율시간 확보용처럼 보이면
  `[필수] 1학기에 반영. 학교자율시간을 위해 감 한 것처럼 보임. 아래 전부 반영.` (교과(군) 20% 안의 교과 증감 자체는 지침상 가능)
- 학교자율시간 줄 이름이 활동명과 다르면 `[필수] 활동명과 다름.`
- 학년군 합계 칸(두 학년 계를 더한 칸), 연간수업시간수(3~4학년 986, 5~6학년 1,088)도 다시 더해 본다. 틀리면 `[필수] 학년군 합계 계산 오류` + 맞는 숫자 나열.
- 5~6학년 편성표에 3~4학년 기준 시수(과학/실과 204, 영어 136·±27 등)가 남아 있으면 `[필수] 5~6학년 기준 시수·증감 범위와 다름.`
- 증감은 한 학기에 적었는데 편성시수는 두 학기 모두 줄어 있으면 `[필수] … 2학기에서도 1시간 줄어 있음.` + 학기별 총시수 + `고친 예: 1학기 47, 2학기 51`
- 증감 칸 숫자가 1·2학기 편성시수 합과 다르면 `[필수] 국어 증감이 편성시수와 맞지 않음.` + `98+102=200으로 기준 204에서 -4임.`
- 체육·예술 증감 범위를 (±)로 적었으면 `[필수] 체육·예술은 감축 불가이므로 체육 (+40), 음악·미술 (+54)로 표기.`
- 지난 학년도(예: 2026학년도 3학년) 칸이 올해 편성을 그대로 복사한 것이면 `[권장] … 올해 실제 편성 시수로 기재 필요.` (사용자 결정, 2026-11-24)
- 학교자율시간 감축이 운영하지 않는 학기에도 나뉘어 학기별 총시수가 달라지면 `[필수] 학교자율시간 확보를 위한 감축은 운영 학기(1학기)에 반영 필요. 아래 전부 반영.` + 학기별 총시수
- 증감 칸이 빈칸인데 편성시수가 기준과 다르면 `[필수] … 증감 칸이 비어 있음.`

### 서식1 계획서
- 편성 교과에 선택(■)이 없으면 `[필수] 편성 교과가 선택되지 않음.` + 성취기준 코드 글자에 맞는 교과
- 활동명이 세부 지도계획안과 띄어쓰기까지 다르면 `[필수]`
- 교재 구분이 '기존 개발 도서(교과용 도서)'인데 시판 교재(차례를 그대로 옮긴 차시)로 보이면 `[필수] 교재 구분 확인 필요.` + '교과용 도서는 인정도서에 해당함. 시판 교재는 교수학습자료로 표시하고 자료명(출판사 포함) 기재' (사용자 결정, 2026-11-24)
- 서식6 체크리스트 검토 결과(○, X)가 모두 빈칸 → `[권장] 체크리스트 검토 결과(○, X)가 모두 빈칸임.`
- 교재/자료명 빈칸, 붙임 `( )` 빈칸 → `[필수] … 빈칸임.` + `고친 예:`

### 공통
- 오타는 `[필수] 오타` + `고친 예: 맞는 글자` (문장 호응이 어색하면 `[필수] 문장 호응이 어색해 보임.`)

## 4. 사용자가 뺀 것 (이런 메모는 달지 않음)
- 지침 예시안 문장을 거의 그대로 옮겼다는 지적
- 핵심아이디어를 통째로 다시 쓴 긴 `고친 예` (5·6학년처럼 문장 수·성격만 지적)
- 평가 시기가 진도보다 이르다는 추측성 지적
- 성취수준 C의 '도움이 필요하다' 표현
- 다른 학년 활동 연계를 확인 질문으로 묻는 것 → 필요 없으면 바로 `[권장] 삭제`

## 5. 한글 메모 만들기 (`scripts/hwpx-memo/`)
- `addmemo.py 원본.hwpx 결과.hwpx 학년` — 메모 목록 파일(`MEMOS_MODULE`, 기본 `memos`)의 `{학년: [{find, nth, tag, body, fix}]}`를 넣는다.
  `FIX_PREFIX="고친 예: "`로 고친 예 앞말을 정한다. `--dry`로 붙일 자리만 확인.
- 한글이 '손상·변조'로 막지 않게 꼭 지킨 것: 메모 필드 종류 번호 `fieldid="623209829"`(고정값),
  문서의 '메모' 스타일(paraPr·charPr·style id) 사용, 메모를 넣은 문단의 `<hp:linesegarray>`(줄 배치 정보) 삭제.
- `fixflags.py 원본 결과` — zip 압축 옵션 비트를 원본과 같게.
- 메모 목록의 `body`에 `\n`을 넣으면 여러 줄 메모가 된다 ((예시) 다음 줄부터 모범 문장).
- `relabel.py 원본 결과` — 메모 구분 표시만 `[필수]`/`[권장]`으로 바꿈 (본문은 그대로).
- `readmemo.py 파일.hwpx` — 사용자가 고친 메모 읽기 (대상 글자·작성자·내용).
- `stripmemo.py 원본 결과` — 문서에 이미 있는 메모를 모두 지움. 사용자가 단 짧은 메모(HK 등)를 구체적으로 다시 쓸 때는
  지우고 같은 글자에 `컨설팅` 메모로 새로 단다 (사용자 결정, 2026-11-20).
- 메모 목록에서 숫자 칸(편성표)처럼 같은 글자가 여러 번 나오면 `nth`를 `dump.py` 번호로 세어 정한다.
- 메모 목록 파일을 다른 폴더에 두면 `addmemo.py`를 절대 경로로 실행한다 (스크립트 폴더를 import 경로로 씀).
- `dump.py 파일.hwpx` — 메모를 붙일 글자 찾기 (본문 `<hp:t>` 목록).
- 만든 뒤 앱의 `hwpxSectionText`로 원본과 본문 글자가 같은지 확인한다.
