# 학교자율시간 계획서 컨설팅 기준 (메모 작성 방법)

다른 학교의 학교자율시간 계획서(한글 hwpx)를 컨설팅할 때 쓰는 기준이다.
2026-11 광양 지역 학교 3~6학년 활동 문서 컨설팅에서 사용자가 직접 고친 메모(2회)를 바탕으로 정리했다.
근거: 「2027학년도 초등 학교자율시간 설계·운영 지침」, 2027 연수 PPT, 앱 규칙(`docs/guideline-summary.md`).
모범 양식: 「지구촌, 함께 걷는 우리」(활동 예시안) — 학교에 '제공한 양식'으로 안내한다.

## 1. 결과물

- 원본 hwpx에 **한글 메모**를 단 파일 (작성자 `컨설팅`). 만드는 방법은 아래 5절.
- 메모가 안 열릴 때를 대비한 쪽·줄 목록(docx)은 요청이 있을 때만.

## 2. 메모 말투·형식 (사용자가 고친 형태)

- **첫 줄 = `[구분] 짧은 진술`**. 한 줄로 끝나면 그것만 쓴다. 예: `[확인] 활동명과 다름.`, `[권장] 삭제`
- 필요할 때만 한두 문장 덧붙인다. 설명을 길게 쓰지 않는다.
- 종결은 **'~함 / ~임 / ~필요'** (개조식). '~요, ~니다'는 쓰지 않는다.
- 판단이 들어가면 단정하지 않는다: `~가까워 보임`, `~거리가 있어 보임`, `~가 아닌가 함`, `~어렵지 않을까 싶음`.
- 성취기준 코드 대신 **단원 이름**으로 가리킨다: `2단원 기후변화와 자원 고갈 내용에 가까워 보임`.
- 고칠 모양을 보여 줄 때는 `고친 예: …` (짧은 것) 또는 `(예시)` 다음 줄부터 모범 양식 문장을 그대로(여러 줄).
- 구분 표시: `[지침]` 지침·양식 근거(고쳐야 함), `[연수]` 연수 자료 근거, `[권장]` 더 좋게, `[확인]` 학교가 사실 확인.
  (사용자는 양식에 맞지 않는 것도 `[지침]`으로 씀)

## 3. 점검 항목과 메모 문구 (붙이는 자리 → 메모)

### 계획서(서식1)
| 자리 | 메모 |
|---|---|
| 편성 교과에 ■가 두 개 | `[지침] 편성 교과는 하나만 선택해야 함.` / `성취기준 코드의 편성교과 글자도 하나로 정해짐.` / (학년들이 같은 교과면) `3-6학년이 모두 과학이므로 과학을 추천(시수 확보)` 또는 `고친 예: 과학 또는 실과 중 하나만` |

### 활동 교육과정(서식2) 전체
| 자리 | 메모 |
|---|---|
| `학교자율시간 활동 교육과정 문서 체제` 제목 (예시안과 다른 옛 양식) | `[지침] 활동 교육과정 문서 양식과 맞지 않음. 제공한 ‘지구촌 함께 걷는 우리’ 양식에 맞춰 수정 필요.` |

### 1. 필요성 및 목표
| 자리 | 메모 |
|---|---|
| `필요성 및 목표` 제목 (필요성이 여러 문단) | `[지침]사회현상 및 시대적 요구 + 학생들이 해당 활동을 배워야 하는 까닭 + 기르고자 하는 학생상 혹은 역량을 한 문단으로 기술` |
| 총괄 목표 문단이 `이를 위해`로 시작 | `[지침] 이에 따라 <활동명>는~ 시작하도록 변경` |
| 다른 학년 활동을 배웠다고 전제한 문장(그 학생들은 아직 안 배움) | 문장마다 `[권장] 삭제` |
| 세부 목표 3개가 순서대로 지식·이해 / 과정·기능 / 가치·태도에 맞는지 | 어긋나면 `[지침] 지식이해 목표가 아닌 과정기능 목표에 해당됨`, `[지침] 가치태도의 목표와 맞지 않음` (어긋난 구절에) |

### 2. 내용 체계
| 자리 | 메모 |
|---|---|
| 핵심아이디어가 '학생들이 …하도록 한다', '…교육은 …목표로 한다' | `[지침] 핵심아이디어 진술 방식` / `핵심아이디어는 '활동의 학습을 통해 일반화할 수 있는 내용을 핵심적으로 기술'함. 현재 문장은 교육 목표에 가까움.` (+ 개수가 영역 수와 다르면 `영역(2개)과 핵심아이디어(3개)의 수도 맞지 않음.`) |
| `내용 요소` 머리칸 (영역 구분 없음) | `[권장] 각 영역별로 나누기` / `단원이 3개이므로 영역이 3개로 나뉘어야 하며, 성취기준도 각 영역별로 2-3개씩 있어야 함.` |
| 과정·기능 요소가 '~하기'가 아님 | `[연수] 과정·기능 내용 요소는 '~하기'` + `고친 예:` |
| 가치·태도에 활동이 들어감('실천 계획 수립' 등) | `[권장] 활동(과정·기능) 성격임.` + `고친 예: …태도/의지` |
| 가치·태도가 한 차시 활동 서술 | `[권장] 한 차시 활동에 가까움.` + `고친 예:` |

### 3. 성취기준
| 자리 | 메모 |
|---|---|
| `3. 성취기준` 제목 (성취기준에 안 들어간 내용 요소가 있음) | `[연수] 내용 요소의 모든 내용들이 성취기준에 들어가야함.` + `(예: ‘…’, ‘…’)` (실제로 빠진 요소를 대조해서) |
| 첫 성취기준 코드 (교과 글자 없음 / 약어 1글자) | `[지침] 성취기준 코드에 편성교과 글자가 없음` + `고친 예: [3과지구01-01]` |
| 첫 '~할 수 있다' 문장 (한 번만) | `[권장] 성취기준은 '학생이 도달할 결과'이므로 2022 개정 교육과정처럼 '~한다.'로 진술하면 더 분명함.` |

### 4. 지도의 실제 — 단원 지도계획
| 자리 | 메모 |
|---|---|
| `가. 단원 지도계획` 제목 (평가 차시 표시 없음) | 아래 그대로 |
| 첫 차시 학습 내용 (형식이 다름) | 아래 그대로 |
| 성취기준·단원과 어긋난 차시 | `[권장] '자원과 에너지'는 2단원 기후변화와 자원 고갈 내용에 가까워 보임.` 같은 한 줄 |
| 학년 수준에 어려운 주제 | `[권장] …3학년에게 어려운 논쟁 주제가 아닌가 함.` |

```
[연수] 평가하는 차시가 단원 지도계획에 드러나지 않음
(예시) 해당 차시 사각 박스 안에 넣기
[과정중심평가] 평화와 존중을 주제로 발표하고 함께 더불어 살아갈 것을 다짐하기
```
```
[지침] 기술 방법이 다름
(예시)
·급변하는 사회에서 나타나는 문제에 대해 알아보기
  - 그림책을 읽고, 급변하는 사회에서 나타나는 문제를 여러 가지 문제 생각해 보기
  - 지구촌의 여러 문제에 관심갖기
```
(학습 내용은 `·학습 목표(~알아보기)` 다음 줄에 `  - 세부 활동`. `·지속 가능한 지구란?`처럼 질문형 제목이나 `·` 줄만 나열한 것은 이 메모)

### 4. 지도의 실제 — 평가 계획
| 자리 | 메모 |
|---|---|
| `수업·평가 방법, 연계의 주안점` 머리칸 (양식대로 안 씀) | 아래 그대로 |
| 성취수준 C가 '미흡하다·못한다' | `[권장] C 수준도 도달한 모습을 긍정형으로 진술 필요.` (사용자는 '도움이 필요하다'는 그대로 둠) |

```
[지침] 양식에 맞지 않게 기재됨.
(예시)
[협력중심 학습]
▪ 평화와 존중을 주제로 발표하고 함께 더불어 살아갈 것을 다짐하기
⇒ (관찰평가, 동료평가) 모둠 내 역할 분담과 협력 과정, 발표 참여도를 교사가 관찰하고 동료평가로 협력 정도를 함께 확인함.
```

### 붙임2 편성표
- 숫자(학기별 증감·편성, 소계, 창체, 연간 총시수, 교과(군) 20% 범위, 체육·예술 감축 금지, ※ 확보 내역 합계)를 계산해 확인. 맞으면 메모 없음.
- 학교자율시간 줄 이름이 활동명과 다르면 `[확인] 활동명과 다름.`

## 4. 사용자가 뺀 것 (이런 메모는 달지 않음)
- 지침 예시안 문장을 거의 그대로 옮겼다는 지적
- 핵심아이디어를 통째로 다시 쓴 긴 `고친 예` (5·6학년처럼 문장 수·성격만 지적)
- 평가 시기가 진도보다 이르다는 추측성 지적
- 성취수준 C의 '도움이 필요하다' 표현
- 다른 학년 활동 연계를 '[확인]'으로 묻는 것 → 필요 없으면 바로 `[권장] 삭제`

## 5. 한글 메모 만들기 (`scripts/hwpx-memo/`)
- `addmemo.py 원본.hwpx 결과.hwpx 학년` — 메모 목록 파일(`MEMOS_MODULE`, 기본 `memos`)의 `{학년: [{find, nth, tag, body, fix}]}`를 넣는다.
  `FIX_PREFIX="고친 예: "`로 고친 예 앞말을 정한다. `--dry`로 붙일 자리만 확인.
- 한글이 '손상·변조'로 막지 않게 꼭 지킨 것: 메모 필드 종류 번호 `fieldid="623209829"`(고정값),
  문서의 '메모' 스타일(paraPr·charPr·style id) 사용, 메모를 넣은 문단의 `<hp:linesegarray>`(줄 배치 정보) 삭제.
- `fixflags.py 원본 결과` — zip 압축 옵션 비트를 원본과 같게.
- `readmemo.py 파일.hwpx` — 사용자가 고친 메모 읽기 (대상 글자·작성자·내용).
- `dump.py 파일.hwpx` — 메모를 붙일 글자 찾기 (본문 `<hp:t>` 목록).
- 만든 뒤 앱의 `hwpxSectionText`로 원본과 본문 글자가 같은지 확인한다.
